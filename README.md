# نظام الفواتير الإلكترونية والامتثال الزكوي - مؤسسة رند العز للمقاولات العامة

نظام شامل لإدارة الفواتير، العملاء، والربط والامتثال للفوترة الإلكترونية لهيئة الزكاة والضريبة والجمارك (ZATCA Phase 1 & Phase 2).

## المميزات التقنية:

- **واجهة المستخدم:** React + Vite + TypeScript + Tailwind CSS + shadcn/ui.
- **دعم اللغة والاتجاه:** Arabic RTL و English LTR.
- **توليد الفواتير:** تصدير PDF احترافي مع دعم خلفية الفاتورة والترويسة المعتمدة.
- **الامتثال الزكوي:** توليد وتشفير كود UBL 2.1 XML، وبصمة التشفير SHA-256، ورمز الاستجابة السريعة TLV Base64 QR Code.
- **قاعدة البيانات:** PostgreSQL عبر Supabase مع سياسات أمان صارمة (RLS).
- **التحكم بالصلاحيات (RBAC):** مدير النظام (Admin)، محاسب (Accountant)، وقارئ فقط (Viewer).
- **إدارة العملاء:** مطابقة لبيانات العنوان الوطني والرقم الضريبي والسجل التجاري السعودي.

## التشغيل المحلي:

```bash
npm install
npm run dev
```
